# Dleading Web Design Ltd — Website Redesign

Responsive multi-page redesign for Dleading Web Design Ltd, built by DEVLYON with lightweight HTML, CSS and JavaScript.

## Pages
- Home — index.html
- About — about.html
- Services — services.html
- Portfolio — portfolio.html
- Contact — contact.html
- Blog — blog.html (links to Dleading's existing blog)

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (DM Sans, Manrope)

## Deployment
Static website. Cloudflare Pages can deploy this repository with no build command and the root as the output directory.

## Contact form
The form prepares an inquiry through the visitor's email app (mailto). It is not server-backed and requires the visitor to send the email.

## Assets
The homepage currently uses a branded SVG silhouette placeholder for its hero portrait. Replace assets/founder-placeholder.svg with the approved founder portrait asset when it can be added to the repository.
